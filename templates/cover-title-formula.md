# 标题与封面公式（双层标题）

## 1. 局名（≤4 字，封面主文字，catalog 登记）
构词法（任选其一，读起来像一个“局”）：
- 数字+道具：七天金条、五囚二弹、四药两天
- 道具+局型：密码死局、红包陷阱、三灯盲局、过河迷局
- 场景+结果：黑屋分钱、暴雨打卡、盲盒识毒
禁忌：不含答案、不含解法词（“对半切”“倒推”不能上封面）；同系列局名不重复用字过多；不与已研究参考账号的局名完全相同。

## 2. 平台标题（≤30 字，完整问句）
模板：`具体情境 + 具体数字 + 约束/代价 + 反问`
- “{数字}{道具}{事故}，你怎么保证{目标}？”
- “只有{一次/一把/两颗}{资源}，怎么{目标}？”
- “{看似简单的情境}，为什么{反直觉结论}？”
- “{数字}人{处境}，怎么让{数字}人绝对{结果}？”
规则：数字写阿拉伯数字；出现“你”；不剧透机制词；可加一个悬念短语（“算错一步直接出局”），不用“99%的人”类夸张（可选，需品牌决定）。

## 3. 封面版式（与 branding 决定的底色一致）
- 一个道具图标居中（生图，扁平、单一本色），周围留白 ≥ 25%。
- 局名大字（≤4 字，粗体，白描边或分隔线），小字一行系列名/编号。
- 无答案、无长句、无多余人物；水印位置固定。
- 同系列版式一次性统一；改版全量重做而非混用。
- 4:3 与 16:9 同源导出（按 branding 规则）。

## 4. 登记字段（写入 catalog 与发布文案）
`game_name`（局名）、`title`（平台标题）、`principle_name`（结尾原理名）、`hook_numbers`（标题中的数字）、`differentiation`（若参考账号已发布同机制题：差异化说明）。
