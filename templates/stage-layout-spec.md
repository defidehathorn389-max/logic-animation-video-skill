# 舞台版式与动画词汇表（代码驱动动画用）

用途：分镜（storyboard）与渲染脚本共用的版式、状态标注与动画时长约定。目标是“一期一个舞台，靠元素进出和标注变化表演”，所有数值来自确定性状态模型，画面不手工摆数字。

## 1. 版式（1920×1080）

```
┌──────────────────────────────────────────────────────────────┐
│ 角标(左上)          状态栏(左上下方: 计时器/天数/剩余)  规则卡(上中)   免责小字(右上,需授权) │
│                                                              │
│  起点/一方(左侧)          舞台中心：道具/桌面/河道/房间          终点/另一方(右侧)  │
│  实体行：头顶属性标签(数字) + 脚下编号/名字                      │
│                                                              │
│ 讲解者(左下或右下, 小尺寸, 不遮舞台)     短语级字幕(底部 1/6 处居中)          │
└──────────────────────────────────────────────────────────────┘
```
- 舞台底色：浅灰（亮度约 180/255）；线稿黑；一种道具本色作为唯一彩色；红=错误/危险，绿=确认/安全，黄=强调/原理名。
- 实体（人物/物件）成行排列，间距一致；头顶一个属性标签（“2分钟”“1000枚”），脚下一个编号（1–5 或 甲乙丙丁）。
- 双方/两岸/两天的状态**同时在画**（左右各一列或上下各一行），不用来回切镜。
- 规则卡：白底黑框卡片，出现在上中或旁白提到规则的位置，关键词变色。
- 汇总板：白板列出每步操作与数值（第 1 趟 3 分钟…总计 17 分钟），在证明段出现。
- 思考拍：整幅压暗到约 45% 亮度，中央大号白色数字或问号，1.5–3s（采用哪种由项目品牌决定）。

## 2. 状态标注词汇（每一步至少一个）

| 语义 | 标注 |
|---|---|
| 已确定/不可动 | 锁图标、实心边框 |
| 正确/安全 | 绿勾、绿章“正确/安全” |
| 错误/排除/出局 | 红叉、灰化、划线 |
| 目标/危险对象 | 红色瞄准圈、红色虚线框 |
| 当前操作对象 | 黄色描边或黄底 |
| 数量/剩余/时间 | 计数器徽章（21→20→17）、计时器、日历日 |
| 分案 | 右上角“情况一/情况二”标签 |
| 想法/策略 | 思维气泡（先气泡后文字） |
| 疑问 | 人物头顶“?” |
| 命名原理 | 黄色大字（≤4 字）+ 白描边 |

## 3. 动画词汇与时长（30fps，缓动 ease-out 为主）

| 动作 | 时长 | 说明 |
|---|---|---|
| 弹入 pop-in | 0.15–0.25s | 缩放 0→1.1→1；一组元素按 0.08–0.12s 间隔错开 |
| 上滑入场 slide-up | 0.3s | 桌面/场景元素从下方 40–80px 滑入并淡入 |
| 气泡展开 | 0.4s 分 3 级缩放 | 文字在气泡完成后 0.3–0.6s 出现 |
| 图标动作（刀切/翻面/敲击） | 0.3–0.5s | 图标覆盖在对象上做一次位移/旋转，随后对象变形 |
| 对象变形（整→半、开→关） | 0.2s | 直接替换贴图并微缩放 |
| 沿路径飞行（进盘/过河/换手） | 0.5–0.8s | ease-in-out，落点处轻微回弹；目的地容器先出现 |
| 标注盖章（勾/叉/章/锁） | 0.2s | 缩放 1.3→1，可加 1 帧微抖 |
| 计数器跳变 | 0.2s | 旧数字上移淡出、新数字下移淡入 |
| 压暗思考拍 | 0.3s 淡入，停 1.5–2.5s，0.3s 淡出 | 数字/问号弹入 |
| 场景过渡 | 0.2s | 聚光/白闪单帧或直接替换；不做花哨转场 |
| 讲解者入场 | 0.3s | 从画角滑入，只在需要指点/总结时出现 |

同步规则：每个视觉变化的起点对齐旁白中点名该对象/动作的字（用逐字对齐时间轴）；标注在动作完成后 0.1–0.2s 出现；同一秒内不超过 2 个新元素。

## 4. 音频
- 旁白为主；垫乐为低音量持续性铺底（不抢节奏），关键动作可配轻量音效（弹入“啵”、盖章“咔”、错误“嘟”），音效峰值不高于旁白。
- 交付前测整体响度/LRA/真峰值，系列一致。

## 5. 素材来源
- 人物、道具由生图工具产出多姿态/多状态贴图（同一角色固定设定，透明背景，成组生成保证一致）；文字、数字、计数、公式、标注一律代码绘制。
- 每个道具至少准备：默认态、高亮态、错误态、变形态（如整/半、开/关、正/反）。
