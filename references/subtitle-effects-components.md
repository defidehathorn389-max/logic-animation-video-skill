# 可复用字幕动效与原创音效组件

## 使用范围与边界
- 实现：`tools/subtitle_effects.py`，11种参数化2D动效＋5类程序合成音效；不含参考视频、作者字体、贴图、音轨或编辑器商业预设。
- 参考片段中的动画标签可以指导分类，不能证明其内部缓动曲线、插件参数或独立音效名称。以下时长和曲线均为本工具的原创起始参数，不是从参考工程提取的精确值。
- 参考中同一种入场可用于不同语义；组件按动作去重，不按示例文案复制。2D翻转/滚动为近似实现，不冒充编辑器原预设或真实三维圆柱。
- 已批准的正文字幕字形、字号、颜色、描边与逐字时间轴不得自动替换。新库默认可选，只适合少量标题/关键词/动作标注。更换已批字幕需单独批准。

## 默认参数（可调，非实测还原）
| ID | 运动 | 秒 | 可选原创音效 |
|---|---|---:|---|
| drop | 上方28px落定，三次缓出 | .24 | soft_thump |
| flip | 纵向投影展开至1，少量位移 | .28 | air_swipe |
| rise | 字间35ms错开，上升并回正 | .26 | tick |
| impact | ≤18%轻冲击与短模糊 | .22 | soft_thump |
| roll | 纵向投影、位移和≤8°回正 | .32 | air_swipe |
| snow | 确定性错位/旋转后归位，错开35ms | .38 | glass_ping |
| shake | 水平≤6px、垂直≤2px衰减震动 | .32 | low_pulse |
| zoom | 0.85→1.0，不从0缩放 | .22 | soft_thump |
| zoom_shake | 0.88→1.0，≤5px衰减震动 | .28 | soft_thump |
| dissolve | 固定随机种子的像素透明度溶解 | .30 | air_swipe |
| fade | 三次缓出渐显 | .30 | glass_ping |

## 音画触发与混音
- `pose(name, elapsed, index)` 返回变换；`transform(rgba, name, elapsed, index)` 返回图块和偏移。elapsed相对真实声学或动作事件，而不是按字数估计。
- 声效由 `synth()` 原创合成：短低频落点、空气扫过、轻点击、玻璃感提示、低频脉冲。名称描述本实现意图，并非对参考音效的人工听感认定。
- 只在语义/动作节点触发，不对每个字打点。`mix_events` 要求至少120ms间隔，默认峰值−32dBFS；混后必须另测LUFS和真峰值，采样峰值检查不能替代真峰值。
- 音效不得盖住辅音、旁白尾音或缩短思考停顿。无法分离参考音轨时，不从混合音轨截取波形冒充独立素材。
- 震动、翻转、溶解不用于长句和高频持续字幕；同屏只保留一个主要强调动作。动画结束回到稳定可读状态。
